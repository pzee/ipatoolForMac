## 本版本

- 不再内置 `ipatool`，统一使用 Homebrew 安装的版本
- 新增简体中文与英文切换
- 下载列表支持删除 IPA，并自动清理已经不存在的记录
- 优化登录凭证访问，减少钥匙串授权提示

## 安装

1. 安装 `ipatool`：`brew install ipatool`
2. 下载 `ipatool.For.Mac.dmg`，打开后将 `IPA Tool` 拖到「应用程序」
3. 应用尚未经过 Apple 公证。如首次打开被拦截，请运行：

```bash
xattr -rd com.apple.quarantine /Applications/IPA\ Tool.app/
```

系统要求：macOS 13 或更高。支持 Apple 芯片和 Intel Mac。
